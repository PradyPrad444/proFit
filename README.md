ProFit is a mobile application built with React Native that helps users organize their wardrobe and generate creative outfit ideas. By uploading photos of clothing items, users can build a digital closet. ProFit uses an integrated AI agent to recommend outfit combinations based on clothing colors, user skin tones, personal preferences, and weather conditions.

**Features**

Wardrobe Management
Upload and save clothing items to your digital closet with automatic background removal.

AI-Powered Outfit Suggestions
Generate personalized outfit recommendations powered by an AI agent that considers style compatibility, color theory, and weather.

Camera Integration
Capture clothing items directly through the app using VisionCamera.

Weather Awareness
Get outfit suggestions that adapt to real-time local weather conditions.

Responsive UI
Clean and intuitive design with React Native and Tailwind styling.

**Tech Stack
**
Frontend: React Native, Tailwind CSS

Camera: React Native VisionCamera

Backend: FastAPI (Python)

Machine Learning / AI Agent: Outfit recommendation engine combining color analysis, style matching, and weather adaptation

Database: MongoDB
